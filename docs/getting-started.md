# 5 分钟快速上手 JuanjuanTeam Skill

> 完全不懂代码？没关系。这份指南用大白话教你从 0 用起来。

---

## 第 1 分钟：这个 skill 是干嘛的？

**一句话**：让 7 个 AI 组成一个团队帮你干活，互相挑错，避免单个 AI 犯迷糊。

想象你装修房子——
- 一个人设计 + 施工 + 验收，容易自我背书（自己做的自己看不出毛病）
- 7 个人分工：1 人管调度、1 人跟你对接、1 人设计、2 人施工、1 人专职挑错、1 人查资料记经验

这 7 个角色会**同时独立审核**同一个方案，不看对方的意见，最后综合出最强方案。

---

## 第 2 分钟：7 个角色都是谁？

| # | 角色 | 类比 | 干嘛的 |
|---|------|------|--------|
| 1 | leader | 项目经理 | 调度，不干活 |
| 2 | convener | 客服+总编 | **唯一跟你说话的人** |
| 3 | architect | 架构师 | 设计、出方案 |
| 4 | frontend | 前端工程师 | 写 UI 代码 |
| 5 | coder | 后端工程师 | 写业务逻辑 |
| 6 | reviewer | 质检员 | 专职挑错，不写代码 |
| 7 | docs-researcher | 文档+资料员 | 查资料、写文档、记经验 |

**记住一点**：你只跟 convener 说话。其他 6 人的产出都汇总到 convener，再转给你。

---

## 第 3 分钟：4 种模式选哪个？

根据你想管多细选一个：

| 模式 | 你要做的事 | 适合 |
|------|----------|------|
| **Safe** | 每个步骤都看一遍确认 | 重要项目、不熟悉时 |
| **Manual** | 你完全审核 | 你想全程掌控 |
| **Auto** | 团队自己审，难点找你 | **日常推荐** |
| **YOLO** | 全交给团队，投票决策 | 信任团队、要快 |

**新手第一次用**：选 **Auto**。既有团队帮你审，又不会完全失控。

## 第 4 分钟：怎么触发？

在 Claude Code 里跟 Claude 说话，自然触发：

**自动触发**（说带动词的任务）：
- "帮我做一个 AI 论文管理系统"  ← 自动触发（多文件新功能）
- "修一下登录 bug"  ← 自动触发（bug 修复）
- "写一个爬虫脚本"  ← 自动触发（新功能）

**显式触发**（直接说关键词）：
- "用卷卷 skill"
- "juanjuan skill"
- "上 juanjuan team"
- "team up"
- "multi-agent"

**不触发**（简单问题）：
- "什么是 React"  ← 纯问答
- "把 foo 改成 bar"  ← 单行修改

## 第 5 分钟：第一次跑会发生什么？

假设你说"帮我做一个待办清单 app"，流程：

```
1. convener 跟你确认需求（头脑风暴）
   "你想要 Web 版还是手机版？数据存哪？"
2. 你选模式
   convener 弹卡片让你选 Safe/Manual/Auto/YOLO
3. 团队建项目目录
   ~/项目/2026-08-04-1430-待办清单-a3f2/
4. architect 出 2-3 个方案
   convener 给你看："方案 A/B/C 各有什么优劣"
5. 三方独立审方案
   architect + reviewer + docs-researcher 各自挑错（不看对方）
6. convener 汇总给你
   "推荐方案 B，理由是..."
7. 写设计文档
8. reviewer 审文档
9. 前端+后端并行写代码
10. reviewer 审代码（OWASP + 测试覆盖率）
11. 自动备份
12. 存经验到记忆库
13. convener 给你最终汇报
```

**全程你只需要在关键节点跟 convener 互动**，其他不用管。

## 常见问题

### Q1：我什么都不懂，能跑起来吗？

能。选 Auto 模式，跟 convener 自然对话即可。它会引导你。

### Q2：跑一半我能打断吗？

能。任何时候跟 convener 说"停一下"/"改个方案"/"我自己审"都行。

### Q3：如果团队给的方案我不满意？

直接跟 convener 说"方案不行，重新做"。它会回到 Phase 3 让 architect 重出。

### Q4：跑一次要多久？

单文件小任务（Lite 模式）：5-10 分钟
多文件新功能（全流程）：30 分钟-2 小时

### Q5：会消耗多少 token？

- Lite 模式：约 5-10 万 token
- 全流程：约 20-50 万 token
- YOLO 模式：可能更多（团队投票消耗）

### Q6：我想改团队配置怎么办？

看 `references/customization.md`，教你改 Agent 个数、prompt、理论框架。

### Q7：跑完之后怎么验证团队真的"对抗"了？

跑 `scripts/meta-verify.sh <项目目录>`，输出 JSON 报告，告诉你：
- 3 方真的独立审核了吗
- convener 真的并行调用了吗
- 记忆闭环通吗
- 备份触发了吗
- 主+sub 双层对抗验证通过吗
